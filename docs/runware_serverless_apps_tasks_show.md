## runware serverless apps tasks show

Show a single application task

```
runware serverless apps tasks show <appId> <taskId> [flags]
```

### Examples

```
  # show a task
  runware serverless apps tasks show my-app 7c9e6679-7425-40de-944b-e07fc1f90ae7
```
